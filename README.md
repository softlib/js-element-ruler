# 元素尺 · Element Ruler

由 `悬停检测右键钉住红框（右键钉住红框 - 显示钉住尺寸）.html` 单页 demo 提炼封装的 Chrome 扩展（Manifest V3，零构建、零依赖）。

## 功能

| 操作 | 效果 |
| --- | --- |
| 悬停元素 | 实时测量宽高，标签跟随显示 `标签名 宽 × 高` |
| 宽高同时超过阈值（默认 > 100px） | 元素自动描红色外框 |
| 在红框元素上右键 | 钉住（永久保留红框 + 左上角实时尺寸标签） |
| 再次右键已钉住元素 / 点击标签上的 × | 解除钉住 |
| 弹出面板「全部清除」 | 一键清除当前页面所有钉住 |

支持同时钉住多个元素；钉住的尺寸随滚动、缩放、窗口变化自动更新。

## 安装（开发者模式加载）

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点击「加载已解压的扩展程序」，选择 `element-ruler` 目录
4. 工具栏出现红色框图标即安装成功

> 如需在本地 `file://` 页面使用：扩展详情页 → 「允许访问文件网址」打开。
> 浏览器内置页面（`chrome://`、Chrome 自带 PDF 查看器等）无法注入内容脚本，属于正常限制。

## 使用

- 点击工具栏图标打开面板：
  - **开关**：总开关（关闭后红框全部隐藏，设置保留）
  - **触发条件**：自定义宽 / 高阈值（默认 100px）
  - **检测元素**：勾选要测量的标签（div / span / p / table / ul / article / section…，至少保留一个）
  - **钉住数量 / 全部清除**：管理当前页面的钉住
- 右键规则：只在「检测元素」上接管右键用于钉住/解除，其余元素保留浏览器原生右键菜单。

## 相比原 demo 的改进

- **不再修改页面 DOM**：原实现会给元素加 class、强制改 `position: relative`，可能破坏页面布局；本扩展把外框、尺寸标签、提示气泡全部画在一个独立的 Shadow DOM 覆盖层里（`z-index: 2147483647`），页面零侵入。
- **命中更准**：用 `elementFromPoint` 做命中检测，画出的框与右键目标严格一致，不会被子元素嵌套带偏。
- **按需重绘**：仅在鼠标移动 / 滚动 / 缩放 / 被钉元素尺寸变化时渲染，无常驻轮询。
- **设置持久化**：阈值、标签选择、开关状态存入 `chrome.storage.sync`，跨设备同步。

## 目录结构

```
element-ruler/
├── manifest.json            # MV3 清单（仅需 storage 权限）
├── icons/                   # 16 / 32 / 48 / 128 图标
└── src/
    ├── content/
    │   └── content.js       # 核心逻辑：命中检测 → 悬停框 → 钉住管理 → 覆盖层渲染
    └── popup/
        ├── popup.html       # 面板结构
        ├── popup.css        # 面板样式（自动适配深色模式）
        └── popup.js         # 设置读写 + 与内容脚本通信
```
